# Key Performance Indicators (KPIs)

| KPI                                 | Target / Metric                                |
|-------------------------------------|------------------------------------------------|
| Port Coverage                       | ≥ 95% of ports scanned                         |
| Vulnerabilities Identified          | ≥ 5 valid findings                             |
| Exploitation Success Rate           | ≥ 40% of attempted exploits succeed            |
| Total Time to Complete              | ≤ 20 days                   |
| Report Completeness                 | 100% of sections fully documented              |
| Recommendation Quality              | ≥ 80% actionable and realistic remediation     |
