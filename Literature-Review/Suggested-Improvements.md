# Suggested Improvements

Based on the lecturer’s feedback and review of the project progress, the following improvements are recommended:

## 1. Documentation Enhancements
- Add more references to cybersecurity standards such as OWASP, MITRE ATT&CK, and NIST guidelines.
- Expand the explanation of each identified vulnerability with real-world impact and mitigation steps.
- Enhance diagrams in the System Analysis & Design section (DFD, Sequence Diagrams, etc.).

## 2. Technical Improvements
- Include additional enumeration techniques for SMB, FTP, and VNC.
- Perform manual exploitation attempts in addition to automated Metasploit exploits.
- Add post-exploitation steps such as privilege escalation, file extraction, or password dumping (if applicable).

## 3. Reporting & Presentation
- Add a visual timeline or flowchart for the testing process.
- Improve final presentation slides with diagrams and clear breakdown of results.
- Include a summary table of all vulnerabilities discovered with severity and CVSS scoring.

## 4. Repository Improvements
- Organize folder structure more clearly.  
- Include a more detailed README with installation steps and methodology overview.
