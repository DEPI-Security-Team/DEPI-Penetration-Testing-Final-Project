# Use Case Diagram & Descriptions

## Actors
- Penetration Tester  
- Target System (Metasploitable 2)  

## Use Cases
| Use Case ID | Use Case Name             | Description                                                         |
|------------|---------------------------|---------------------------------------------------------------------|
| UC01       | Scan Ports                | The tester scans all open ports on the target system using Nmap.     |
| UC02       | Enumerate Services        | Identify services running on discovered ports and gather details.   |
| UC03       | Exploit Vulnerabilities   | Attempt exploitation using Metasploit or manual techniques.         |
| UC04       | Post-Exploitation         | Perform privilege escalation, persistence, and credential extraction. |
| UC05       | Collect Evidence          | Gather screenshots, logs, and output files for documentation.      |
| UC06       | Generate Report           | Compile all findings and recommendations into a structured report. |
