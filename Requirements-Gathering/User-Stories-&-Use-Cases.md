# User Stories & Use Cases

## 1. User Stories

| ID | As a…            | I want…                                  | So that…                                   |
|----|-----------------|-----------------------------------------|-------------------------------------------|
| US01 | Penetration Tester | to scan all open ports on the target   | I can identify potential entry points    |
| US02 | Penetration Tester | to enumerate services on each port     | I can detect vulnerabilities             |
| US03 | Penetration Tester | to attempt exploitation of selected vulnerabilities | I can demonstrate security impact  |
| US04 | Penetration Tester | to perform post‑exploitation activities| I can assess the full extent of system compromise|
| US05 | Penetration Tester | to collect and document evidence       | I can provide a detailed report for mitigation |

- Actors: Penetration Tester, Target System  
- Main Use Cases: Scan Ports → Enumerate Services → Exploit Vulnerabilities →→ Post‑Exploitation Collect Evidence → Generate Report
