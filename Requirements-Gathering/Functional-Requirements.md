# Functional Requirements

The system/project must provide the following functionalities:

1. **Port Scanning**
   - Detect open ports using Nmap.
   - Identify service versions for each open port.

2. **Service Enumeration**
   - Enumerate FTP, SMB, VNC, IRC, and Java RMI services.
   - Identify misconfigurations and possible attack vectors.

3. **Exploitation**
   - Exploit vulnerabilities using Metasploit modules or manual techniques.
   - Capture proof-of-concept shells or outputs.

4. **Evidence Collection**
   - Save logs, screenshots, and outputs.
   - Organize evidence per target and per service.

5. **Reporting**
   - Generate a structured final report including vulnerabilities, exploitation results, and remediation recommendations.
