# Stakeholder Analysis

## 1. Stakeholders

| Stakeholder                  | Role / Interest                                   | Priority | Notes                                      |
|-------------------------------|-------------------------------------------------|----------|--------------------------------------------|
| Project Supervisor / Lecturer | Oversees project progress, provides guidance   | High     | Provides feedback and evaluates deliverables |
| Student / Team Members        | Executes project tasks, documents findings     | High     | Responsible for planning, testing, and reporting |
| Target System (Metasploitable 2) | Test environment for penetration testing    | Medium   | Controlled environment, isolated network    |
| Tools & Software Providers    | Nmap, Metasploit, other penetration testing tools | Medium | Ensure tools are compatible and updated      |
| Academic Institution          | Requires project submission for grading        | High     | Compliance with academic rules and deadlines |

## 2. Objectives of Stakeholder Analysis
- Identify key stakeholders and their expectations.  
- Define communication methods for feedback and reporting.  
- Determine priorities and critical resources for successful project execution.
